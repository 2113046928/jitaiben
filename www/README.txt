机台本
================================
报警速查 · 设备结构 · 间隔复习 · 随手笔记
数据只存在本机，不上传、不联网。

怎么打开
--------
电脑：双击 index.html，用 Chrome 或 Edge 打开。
iPhone / iPad：把整个文件夹放到能被访问的地方，用 Safari 打开 index.html，
              点分享 →「添加到主屏幕」，就会像 App 一样全屏运行（有图标、没有地址栏）。
安卓：Chrome 打开后「添加到主屏幕」，同样全屏。

要让它像真正的 App 一样离线可用，需要一个 http 地址（本机跑个小服务、
或者放到任意静态托管都行）。直接双击本地文件也能用，只是不支持离线缓存。

五个页面
--------
速查   输报警号或现象，查到处理步骤，勾完记一次处理。
设备   自己添加机台，选结构模板，得到可点的结构图 + 部件知识。
记忆   间隔重复复习，遗忘曲线自己算。
笔记   调机、交接、参数。
我的   导出备份、导入、恢复预置。

设备怎么加
----------
设备页右上角「＋」→ 填名称/型号/工位 → 选结构模板，两条路：

一、内置模板（适合通用设备）
  取放头 / 供料器 / 传送段 / 伺服轴 / 气缸 / 视觉系统
  结构图是真三维的：
    · 单指拖动 = 转着看
    · 双指捏合 / 滚轮 = 放大缩小，能凑近看细节
    · 点零件 = 弹出它的作用、常见故障、点检方法
    · 「运行」= 让运动部件动起来
    · 「编号」= 显示/隐藏零件编号
    · 「复位」= 回到默认视角

二、拍照建型（适合没有模型的设备）
  模板选「拍照建型」→「拍照 / 选图」→ 拍一张设备正面照。
     · 自动抠出设备的轮廓（背景越干净越准），绿色线就是抠出来的形状
     · 抠得不准就调「容差」；实在不行切「矩形框」
     · 「厚度」决定挤出多深
     · 下面实时看三维效果
  ⚠ 原理是「按轮廓挤出 + 正面贴照片」，不是摄影测量重建：
    正面是实拍，侧面是挤出的壳，转过去看到的是厚度，不是设备的背面。

看完点「标记已学」，设备列表里会显示这台设备学了多少。

⚠ 内置模板是示意几何体，用来认零件、记位置和装配关系，不代表实际尺寸。

数据存在哪
----------
存在这台设备、这个浏览器的本地存储里。换手机、重装系统、清理浏览器数据之前：
  「我的 → 导出备份」，会存成一个 JSON 文件。
恢复：「我的 → 导入备份」，会覆盖当前数据。
「导出台账」出来的纯文本可以直接发微信。
